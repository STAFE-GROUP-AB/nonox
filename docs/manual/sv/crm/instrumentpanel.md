# Översikt för försäljningen

**CRM → Översikt** är startsidan i CRM. Den visar hur försäljningen går, räknat direkt ur affärerna och aktiviteterna.

![Översikten med öppna affärer, andel vunna, säljcykel, affärer utan nästa steg, aktiviteter per vecka och månadens mål.](/bilder/manual/crm/oversikt-forsaljning.webp)

| Nyckeltal | Så räknas det |
|---|---|
| **Öppna affärer** | Antalet öppna affärer och deras värde. **Viktat** är värdet gånger sannolikheten för steget varje affär står i. |
| **Andel vunna** | Vunna affärer delat med vunna och förlorade, för affärer som avslutades under perioden. |
| **Säljcykel i snitt** | Antal dagar från att affären skapades till att den vanns, i snitt för affärer som vanns under perioden. |
| **Utan nästa steg** | Öppna affärer som ingen har planerat något för. Tryck på rutan för att se dem i säljtratten. |
| **Aktiviteter per vecka** | Klarmarkerade samtal, möten, e-post, uppgifter och anteckningar, vecka för vecka de senaste åtta veckorna. |
| **Mål den här månaden** | Hur långt säljarna har kommit mot månadens mål. Se [Prognos och mål](/manual/crm/prognos-och-mal). |

Välj **Period** för andel vunna och säljcykel: de senaste 30, 90 eller 365 dagarna. Välj **Mina** för att se dina egna siffror i stället för hela företagets.
