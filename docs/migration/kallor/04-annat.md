# Annat program

Nästan alla svenska bokföringsprogram kan exportera **SIE typ 4**, det svenska standardformatet för bokföring. Det gäller till exempel Björn Lundén, PE Accounting, Wint och de flesta byråprogram.

- **Bokföringen:** exportera en SIE4-fil för **varje** räkenskapsår. Står det bara "SIE" utan typ, välj den som innehåller verifikationer (typ 4, ibland kallad "4E" eller "4I").
- **Underlag:** ladda ner alla kvitton och fakturor, eller samla pappren per år.
- **Fakturor och register:** spara kundfakturorna som PDF, en lista över obetalda fakturor och, om det går, kund- och leverantörsregistret som fil.
- **Lön:** personallistan, årets summor per anställd, semestersaldona och lönebeskeden som PDF.

Fastnar du: sök på "SIE export" i programmets hjälp, eller fråga oss. Vi hjälper dig gärna.
